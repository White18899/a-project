01 / TEXT FIELD

Dynamic Typography

Add structured headings, descriptions, and lists. Render custom vector typefaces directly on the WebGL canvas with zero pixelation at any scale.

02 / IMAGE FIELD

Rich Media Assets

Inject raster graphics and vector artwork onto your canvas via secure URLs or direct drag-and-drop local file uploads.

03 / TIMER FIELD

Gamified Countdowns

Create countdown widgets that automatically execute specific slides actions, hide overlays, or mark quizzes as timed out once expired.

04 / NAVIGATION BUTTON

Non-Linear Slide Paths

Set custom transition targets on button elements, allowing users to branch off into separate sub-topics, games, or quiz outcomes.

05 / OPTION BUTTON

Interactive Quizzes

Build multi-choice questionnaires. Configure correct answer states, score parameters, and click-response colors instantly.

06 / REVEAL WIDGET

Conceal & Reveal

Bind button controls to reveal hidden components on the slide, perfect for displaying hints, explanations, or hidden clues.

07 / ACTION BUTTON

State Handlers

Trigger state changes, visibility toggles, and coordinate animations dynamically across slide assets upon click.

08 / VIDEO FIELD

Cinematic Canvas

Embed loop-playable, muted, or audio-active video clips directly. Elevate slide cards with interactive video frames.
